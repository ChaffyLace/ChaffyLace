### 📁 Projets Principaux

#### 📦 [Portfolio] Gestion de Stock B2B
*Application web de gestion de stock et d'inventaire en temps réel pour les entreprises.*
- **Technologies :** Python, SQL, HTML5/CSS3, JavaScript
- **Fonctionnalités :** - Suivi des entrées/sorties de marchandises et alertes de stock critique.
  - Tableau de bord analytique pour la visualisation des flux de produits.
  - Gestion des profils utilisateurs (Admin, Gestionnaire d'entrepôt).

#### 🏠 Airbnb Clone
*Réplication complète d'une plateforme de location de type Airbnb.*
- **Technologies :** Python, SQL, Flask, HTML5/CSS3
- **Fonctionnalités :** - Conception d'une API RESTful robuste pour la manipulation des données.
  - Base de données relationnelle structurée pour l'historique des réservations et des utilisateurs.
  - Interface utilisateur dynamique, fluide et totalement responsive.

#### 🐚 Simple Shell
*Développement d'un interpréteur de commandes Unix personnalisé.*
- **Technologies :** Langage C, Bash, Linux, Syscalls
- **Fonctionnalités :** - Exécution des commandes système avec gestion dynamique du `PATH`.
  - Contrôle des processus (fork, wait), manipulation des signaux et gestion des fichiers.
  - Gestion stricte de la mémoire avec traque et correction des fuites via **Valgrind**.
